# ADVERSARIAL REVIEW

Cilj nije potvrda nacrta već pronalaženje razloga za odbacivanje ili odbijanje.

Proveri:
- nadležnost;
- legitimaciju;
- dopuštenost;
- zastarelost;
- odlučne činjenice;
- teret dokazivanja;
- dokazne praznine;
- nepovoljnu praksu;
- protivurečnosti;
- petitum.

Rizik: CRITICAL / HIGH / MEDIUM / LOW.

Za svaki rizik navedi moguću meru za njegovo otklanjanje.

Za pun, dubok red-team prolaz (confirmation bias, simulacija sudije, steelman protivnika, CASE PIVOTS) kod važnijih/spornijih predmeta — v. `18-devils-advocate`.
