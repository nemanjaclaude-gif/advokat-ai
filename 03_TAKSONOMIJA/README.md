# PRAVNA TAKSONOMIJA

Ovde se čuvaju klasifikacioni šifrarnici, npr. zvanična Otvorena lista deskriptora Vrhovnog suda.

Ne praviti folder za svaki deskriptor. Poželjno je imati jedan provereni mašinski čitljiv šifrarnik i koristiti ga kroz skill `02-klasifikacija`.

Tačne numeričke oznake ne unositi iz memorije — samo iz verifikovanog izvora.
